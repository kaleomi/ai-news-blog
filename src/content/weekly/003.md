这一周最戏剧性的是英伟达。上周黄仁勋突然辞职，这周一董事会又把他请了回来，前后只隔 11 天，股价单日涨了约三成。同一周，刚上市的 Anthropic 股价跌破发行价。市场对 AI 头部公司的情绪起伏很大，任何一条人事或股价消息都能被放大。

另一条主线是智能体从「写代码」走到「批准代码」。Anthropic 的 Claude Ship 让智能体按团队规则批准常规改动，OpenAI 和思科开源的 Shirudo 让 Codex 生成的护盾直接挡在生产系统前面，Anthropic 还公开了用 Claude 把自家核心 API 改写成 Rust 的过程。与此同时，Signal 跟在美联航、摩根大通之后限制智能体。一边在放权，一边在设防，两件事会长期并存。

模型方面，这周的新意更多在结构而不是规模：智谱 GLM-5.4 用循环 Transformer 在不加参数的前提下加深计算，中国电信的星辰 4.1 完全用昇腾芯片训练。Anthropic 对 58 家企业的访谈则给出了一个比较克制的结论：AI 目前主要让公司做更多事，直接裁员的很少，但少招人已经很普遍。
